# Lezerv — Android app (Kotlin + Jetpack Compose)

Native implementation of the **Lezerv App v2** design (`../project/Lezerv App v2.dc.html`):
a map-first marketplace where clients find, book and track nearby artisans, and artisans
go online, accept requests, navigate to the client and get paid.

## Open it

1. Android Studio → **Open** → this `android/` folder. Let Gradle sync (it downloads the
   Android Gradle Plugin and Compose from Google's Maven).
2. Run the **app** configuration on an emulator or phone (Android 8.0 / API 26+).

## How the code is organised

```
app/src/main/java/com/lezerv/app/
├── android/MainActivity.kt   Android entry point: fonts, edge-to-edge, system back, ViewModel
├── state/LezervState.kt      ALL app state + actions (ported from the prototype's INIT/tick/handlers)
├── data/SampleData.kt        Sample artisans, prices, copy; formatting helpers (₦, decimals, masking)
└── ui/
    ├── LezervApp.kt          Root: top bars, bottom navigation, snackbar, 100 ms ticker
    ├── theme/Theme.kt        Design tokens (colours, Barlow Condensed / Archivo text styles)
    ├── components/           Blueprint corner marks, buttons, section rules, segments, tags…
    ├── icons/                Lucide icons as SVG path data (generated by tools/gen-icons.mjs)
    ├── map/LzMap.kt          Lezerv's own drawn map of Lekki, pins, rings, routes
    └── screens/              Explore, Profile, Book, Track, Jobs, Messages, Chat, Account,
                              Review, and the artisan Map, Navigate, Jobs, Earnings, Account
```

The pattern is **state → UI**: screens read fields of `LezervState` (Compose snapshot
state) and call its methods; Compose redraws whatever read a field that changed. When the
backend exists, `LezervState`'s actions become calls to a repository, and nothing in
`ui/` needs to know.

## Demo mode

`DEMO_MODE` (in `app/build.gradle.kts`) keeps the prototype's helpers so every flow can be
clicked through on sample data:

- **Account → "Demo · switch to artisan/client"** and **"Demo · reset"** (the prototype's side panel)
- **"Prototype · skip ahead"** on live tracking, **"Demo: fill 4827"** on the start-code step

Try: Explore → tap Tunde's pin → Book now → Pay → watch him drive → skip ahead → Confirm →
Rate and release. Then Account → switch to artisan → go online → Accept → fill 4827 → Start →
Mark complete.

## Fonts and licences

Barlow Condensed (headings) and Archivo (body) are bundled in `res/font` under the SIL Open
Font License (`licenses/`). The Archivo weights were cut from the variable font with
`fonttools varLib.instancer` so they work on every API level.

## verify-desktop/

A separate, optional Gradle build that compiles the same `ui/`, `state/` and `data/` code
for the desktop JVM (Compose Multiplatform) and renders every screen to PNG:

```
cd verify-desktop && gradle renderScreens   # → build/screens/*.png
```

It exists because the cloud environment this was built in could not reach Google's Maven.
You can ignore it in Android Studio, or delete it.
