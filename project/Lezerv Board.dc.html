1Sheet set · round 1 · Android

Lezerv app

Clickable client and artisan flows are in Lezerv App. This board holds the navigation map, flow diagrams, the screens the prototype does not cover, the component library, the mobile type scale and the technical plan.
Assumptions. Android first; the same layouts port to iOS. Industry system: Barlow Condensed, square objects with registration marks, hairlines, one steel accent. Status is shown by label, fill and line style so it reads without colour. Light theme only for v1. Items marked PROPOSAL are new or need a backend change. Nothing in the brief is contradicted.
