02What changed in v2
  • Brand: Lezerv dark green replaces steel blue. Exact hex to be matched from the logo file.
  • Map is the home screen. Every available artisan is a pin; filled means available, outlined means busy.
  • Live tracking for on-site jobs and for laundry pickup and delivery.
  • Industry + Modernist: blueprint corner marks and condensed headings, with Modernist 2px ink rules, flush-left labels and big numerals.
  • Android Material 3 structure: navigation bar, bottom sheets, filter chips, snackbars, system back.
03Build notes · Android Studio
UIKotlin + Jetpack Compose, Material 3. NavigationBar, BottomSheetScaffold, FilterChip, SnackbarHost map one-to-one to this prototype.
MapMapLibre Native (open source) with a custom Lezerv style on OpenStreetMap tiles. No Google branding, POIs or other businesses on the map: only Lezerv pins.
LocationFusedLocationProviderClient. Artisan app sends position every 5–10 s while online or on a job; nearby search via PostGIS ST_DWithin or geohash.
PrivacyClients see an artisan’s approximate area until booking. Exact position is shared only while en route.
ProposalEscrow, start code, masked calls, request timer and payouts need backend work before launch.
